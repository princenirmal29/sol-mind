# SOL-MIND 2.0

A full-stack mental wellness analyzer that evaluates lifestyle signals (sleep, stress, outdoor exposure) and generates insights using a custom scoring system.

## Features
- Light Mind Balance Index (LMBI)
- Smart insights & recommendations
- Weather-aware analysis
- Ambient sound engine
- History tracking

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- APIs: OpenWeather

## How to run

### Backend
cd Backend
npm install
node server.js

### Frontend
Open index.html in browser
